# Introducción a la programación de tabletas Android con Android Studio (2016)

👉 **Curso relacionado:**
[Introducción a la programación de tabletas Android con Android Studio (2016)](https://stahe.github.io/ales-android-aout-2016/)

---

## 📖 Resumen

Este documento es una reescritura y recopilación de diversos recursos de aprendizaje sobre el desarrollo de Android. Su objetivo es ofrecer una **introducción paso a paso y estructurada** a la programación de aplicaciones de Android, especialmente para tabletas.

Incluye una serie de aspectos importantes:

* Introducción a **Android Studio** como principal entorno de desarrollo
* Uso del sistema de compilación **Gradle**
* Introducción a **RxJava** para el manejo de la asincronía
* Estructuración avanzada de aplicaciones de Android (fragmentos, ciclo de vida, arquitectura cliente/servidor)

Este documento se distingue principalmente por la presentación de un **marco genérico para una aplicación Android cliente/servidor**, que puede reutilizarse en numerosos proyectos.



---

## 🎯 Objetivos de aprendizaje

* Comprender los principios básicos del desarrollo para Android
* Dominar la navegación entre vistas y fragmentos
* Administrar el ciclo de vida de los componentes de Android
* Implementar arquitecturas cliente/servidor
* Editar datos a través de interfaces de usuario
* Introducir la programación asíncrona con RxJava
